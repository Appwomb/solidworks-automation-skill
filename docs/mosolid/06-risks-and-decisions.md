# 6. 风险与需要决定的事项

默认建议是在没有新指示时采用的工程选择。未决项不在实现里自行改口。

| 编号 | 决定 | 默认建议 | 不决定时的阻塞 |
|---|---|---|---|

| D3 | 关键写操作审计失败 | 加严：intent 写不下去就不调用 COM；result 写不下去则 BLOCKED，不自动重试。不改现有 Trace 的旁路语义 | P1 的审计门无法定规格 |
| D4 | 桌面壳 | 先沿用本仓库 Tauri CAD Studio。MoAspen 可读并完成差表后，再决定是迁到 MoAspen 壳还是把 MoAspen 的审批/审计迁过来。目标是一个壳，不是两个长期产品 | P5 不开始抽共享库 |

## 6.2 风险

| 风险 | 依据 | 缓解 |
|---|---|---|
| 把 README 的“已真机验证”当成回归基线 | 第 1 篇：多数项目是 E2 或 E3。本环境没有重跑 | 只有本仓库入库的 Golden 算既有证据。MoSolid 总验收按第 5 篇新跑 |
| AGPL 污染公开 MIT 仓库 | SolidPilot 为 AGPL-3.0，且树内含编译好的 exe | D2。评审拒绝新增来自该树的文件 |
| 复制 python 会话代码带上错误的版权人 | LICENSE 与 pyproject 作者不一致 | D10。未确认前自写表结构 |
| 两个桌面分叉 | CAD Studio 已是 Tauri；MoAspen 未读到；Millwright 是 Electron | D4。P5 前不抽库、不引入 Electron |
| 审计加严与旧 Trace 语义打架 | `execution.py` 明确吞掉 Trace 异常 | 新门只用 `mcp_audit.jsonl`。Core eval 必须仍绿 |
| 断线重试打出双特征 | 除 SolidPilot 外没有 operation_id。python 长会话会出现 `RPC_E_DISCONNECTED` | P1 的幂等与 P7 的 F5。变更默认不自动重试 |
| 活动文档被用户切换 | COM API 的活动文档是全局状态 | 每个变更携带文档身份，调用前再读一次 |
| 模态对话框永久卡住 STA | hjbaard 写明超时不能取消已经发出的 COM 调用 | 超时后进程级恢复：停止接收新变更，提示人处理对话框，不 `WM_CLOSE` |
| 索引在改尺寸后指向别的边 | SolidPilot 把 v0 锚点写成 edit-fragile | P2 改尺寸走尺寸名。P6 才验收拓扑引用 |
| 工具 status 成功但几何错 | python `verify_model` 文档；Millwright 写明验证不是门禁 | 完成条件用本仓库聚合规则 |
| 能力清单与 MCP 数量再次漂移 | 本仓库文档 61 与代码 66；其他项目同样 | 契约测试失败即不能合并 |
| 无头或开放格式冒充原生零件 | 本仓库已经禁止改扩展名和空文件 | 总验收要求 `SLDPRT`/`SLDASM`/`SLDDRW` 重开 |
| 真机脚本杀掉用户正在用的 SolidWorks | 本仓库 Golden 文档把此事写成禁止 | 发布脚本发现已有进程则 BLOCKED |
| 一个版本通过就宣布所有版本通过 | 本仓库证据文档写明单机通过不等于发布通过 | D9。报告里写版本字符串和 run 目录 |
| MoAspen 字段与设计稿不一致 | E0 | D6。不一致时改设计稿，不在代码里偷偷兼容 |
| 范围膨胀到 154 或 88 个工具 | 工具数量与可靠性无关，Millwright 对比文也承认这一点 | 白名单只加总验收用到的工具。其余保持 `pilot` 或未注册 |
| 实现者对照 AGPL 源码“改名重写” | 衍生作品风险 | 第 3.3 节第 7 条。P6 评审看 diff 来源 |
| 子模块 SHA 漂到未验收的 main | 方案 B 的操作风险 | 产品仓库只在真机记录更新后改 SHA |
| 许可证联系方式过时 | SolidPilot README 写有商业许可邮箱 | 若走商业许可，以老板与版权人的书面协议为准，不以本文件代替 |
